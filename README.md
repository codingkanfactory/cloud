# ☁️ Cloud — Aplikasi Cuaca Minimalis & Responsif

**Cloud** adalah aplikasi web cuaca modern, cepat, dan responsif yang dirancang untuk memberikan informasi perkiraan cuaca secara akurat dan real-time dengan antarmuka yang bersih, intuitif, serta ramah pengguna.

---

## ✨ Fitur Utama

- 📍 **Pencarian Lokasi Otomatis & Manual**: Mendukung geolokasi otomatis berbasis browser serta pencarian nama kota interaktif menggunakan API Geocoding.
- 🌡️ **Konversi Satuan Suhu**: Berpindah secara instan antara Celcius (°C) dan Fahrenheit (°F).
- 🌓 **Mode Gelap & Terang (Dark/Light Mode)**: Penyesuaian tema otomatis atau manual yang mendukung kenyamanan visual pengguna.
- 📅 **Prakiraan Cuaca 5 Hari**: Menampilkan tren cuaca beberapa hari ke depan dengan ikon visual intuitif.
- ☀️ **Detail Informasi Cuaca**: Kelembapan, Suhu Terasa, Kecepatan Angin, Terbit/Terbenam Matahari, Indeks UV, dll.
- 📱 **Desain Responsif & Aksesibel**: Dioptimalkan untuk perangkat seluler maupun desktop dengan dukungan WCAG.
- 💾 **Persistensi Data**: Menyimpan pengaturan preferensi pengguna (tema, lokasi, satuan suhu) di `localStorage`.

---

## 🛠️ Teknologi yang Digunakan

- **HTML5 & CSS3**
- **Tailwind CSS**
- **JavaScript (Vanilla JS)**
- **Lucide Icons**
- **Open-Meteo API** (Prakiraan Cuaca & Geocoding)
- **BigDataCloud API** (Reverse Geocoding)
